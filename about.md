# List of Geode mods

A hand-picked collection of useful Geode mods for Geometry Dash: bugfixes, quality-of-life
features, editor tools, interface improvements and customization.

DISCLAIMER: This list is created for beginners who downloaded Geode just yesterday. THIS IS MY PERSONAL OPINION! You can download some mods and delete others. The list of mods is intended only for beginners, so I strongly advise you to explore Geode yourself in search of the perfect mod for you.

## Bugfixes & Information

<mod:cvolton.misc_bugfixes>

This mod fixes many noticeable bugs in the game. It also serves as an dependencies to other mods.

<mod:cvolton.betterinfo>

A mod that expands the information about levels and profiles: it shows the ID, the history of daily tasks and chests, comments on deleted levels, profiles of unregistered players, and provides more search options.

## Gameplay & Practice

<mod:elohmrow.death_tracker>

A mod that automatically tracks your deaths, game time, and sessions, allows you to customize the interface and graphs, group sessions by time, create backups, export/import saves, edit them, and includes basic cheat detection (Noclip, Speedhack) and a safe mode.

<mod:manshoety.attemptplayback>

A mod that records every attempt at a level and allows you to replay them in real time, which is perfect for creating awesome videos.

<mod:kevadroz.practicecheckpointpermanence>

A mod that allows you to create permanent checkpoints in practice mode and load them at any time in the future, even between sessions. It’s convenient for practicing complex levels (it replaces copies with Start Pos), works in platformer mode, supports layers and slots for different routes, and includes a checkpoint and save manager.

<mod:undefined0.rewind>

A mod that adds a rewind button in practice mode - it allows you to go back a few seconds and continue the level from the previous point without spamming checkpoints.

<mod:glow12.automaticquests>

A mod that automatically collects completed quests and immediately rewards diamonds, eliminating the need to manually return to the quest menu - allowing you to immediately continue progressing with the next quest.

## Editor

<mod:hjfod.betteredit>

A mod that significantly enhances the level editor: reworked color, font, and movement menus, a View tab for quickly enabling/disabling visuals, improved wheel scrolling, custom grid sizes, an offset for Group ID in Next Free, pinch zoom on mobile devices, a customizable UI scale, and fully custom editor hotkeys.

<mod:mat.circle-tool>

A mod that adds a tool to the editor for duplicating and rotating objects, creating circles or ellipses from them - it works with selected objects and groups the result into a single undoable operation.

<mod:spaghettdev.named-editor-groups>

A mod that allows you to replace numeric IDs (for groups, collisions, counters, timers, effects, and colors) with understandable names stored directly in the level - the names are displayed in the editor, and you can search for, create, export, and import them.


## Interface & Quality of Life

<mod:eclipse.eclipse-menu>

A next‑generation mod menu for Geometry Dash: 100+ cheats, StartPos Switcher, customizable labels and themes, trajectory display, built‑in recorder (FFmpeg API required), Replay Bot, keybindings, and support for Windows, macOS, Android, and iOS. (Also, unlike the Mega Hack by Absolute, this mod is completely free. Also, in my opinion, this is the best mod menu for GD.)

<mod:cdc.level_thumbnails>

A mod that adds preview thumbnails to levels in the search, allows you to take and submit your own thumbnails directly from the game, and through a website linked to a Discord account, you can track the status of requests and rejections.

<mod:hjfod.backups>

A mod that automatically creates local backups of saves at a configurable interval, allows you to import existing backups, and can be used as a profile switcher.

<mod:hjfod.trashcan>

A mod that adds a trash system: deleted levels are first moved to the trash, from where they can be restored, and to permanently delete them, you need to manually empty the trash — items are never deleted automatically.

<mod:hiimjustin000.search_history>

A mod that saves and displays the history of your searches in the level search menu: it includes a pop‑up with the history and advanced filters, the ability to repeat a search from the record, and an incognito mode for searching without saving.

<mod:ninxout.prntscrn>

A mod that adds a convenient screenshot tool in the style of the F2 key from Minecraft: it allows you to take screenshots of levels while hiding the interface, the player, the retry text, practice checkpoints, and other players; it also enables you to automate screenshots by percentage or seconds, adjust dimensions, save in JPG format, and copy to the clipboard.

<mod:alk.better-touch-prio>

A mod that fixes touch input issues by calculating the clickable button based on the Z‑order instead of the touch priority value — this eliminates bugs such as clicking buttons behind non‑hidden popups and clickable layers behind popups.

## Customization

<mod:geode.texture-loader>

The Geode texture pack mod manager: it opens in the graphics settings (on PC) or in the regular settings (on mobile devices), and allows you to add packs in the form of folders, zip or apk files, and apply them to the game by dragging and dropping.

<mod:uproxide.textures>

A mod catalog of texture packs for Texture Loader: it allows you to download packs directly to the Texture Loader folder in the form of zip archives without the need to unpack them, and authors can submit their pack for moderation via the Discord server.

<mod:hiimjustin000.more_icons>

A mod that allows you to install custom icons without any hassle: a gallery, an icon list, viewing and editing icons, color selection, as well as load and save editors.

<mod:ml5.icon-gallery>

A mod version of the Icon Gallery website, which functions as a museum of custom icons: it allows you to search for and install icons directly in the game.

<mod:dasshu.better-gauntlets>

A mod that completely reworks the gantlets in Geometry Dash: an updated interface, new navigation, custom gantlets, and much more.
